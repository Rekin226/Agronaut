# Agronaut 1.4.0 — field agriculture workflows

Agronaut now supports farm records and experimental field irrigation workflows alongside
its aquaponics and hydroponics tools. A grower can keep separate production units, record
planting and observations, calculate water needs, check equipment, log irrigation and
harvest, and review the season.

## Added

- Farms, production units, crop cycles, unit-specific context, and owned observations.
- Crop-water demand, weather provenance, root-zone and layered soil-water accounting,
  with missing inputs and model assumptions visible in results.
- Drip and sprinkler design checks, lateral/network hydraulics, measurement diagnostics,
  and surface-irrigation event and advance analysis.
- Guided planting, scouting, irrigation, measurement, harvest, and task records.
  Corrections and task reviews retain the evidence used for a decision.
- Shared water, supplies, equipment calendars, resource allocations, and recorded use.
- Farm overview, Field records, Crop records, and Farm resources pages alongside the
  existing Assistant, Design, My Twin, and Quality pages.
- French and Traditional Chinese field guidance and deterministic intake flows.
- Reproducible examples, source screening tools, field safety probes, and an installed
  package rehearsal covering a synthetic planting-to-harvest workflow.

This release also includes the changes merged since 1.3.0: cited growth seeds for
barramundi, tambaqui and silver perch; Ethiopian kale and roselle crop entries; entity
provenance; greenhouse source references; provider diagnostics; and WhatsApp follow-up
delivery handling.

## Upgrade

```bash
pip install --upgrade agronaut
agronaut --version
agronaut doctor
agronaut capabilities --system soil
agronaut field-guide --topic choose-method --language fr
```

Existing databases migrate transactionally to schema 25. The upgrade supports both public
schema 2 databases and local field-development schemas through 24, preserving WhatsApp
delivery IDs and field records. Before upgrading an existing database with user tables,
Agronaut writes a SQLite backup beside it, named `<database>.pre-v25-<suffix>.bak`.
Those backups contain the same private records as the original database.

Older versions refuse a schema 25 database. To roll back, retain the backup and restore
it with the previous application version; do not lower the database version stamp.

## Evidence and limitations

The field calculations are **experimental, not field validated**. Automated checks,
published arithmetic references, source audits, and synthetic rehearsals establish
software behavior; they do not establish reliable irrigation timing or yield predictions
for a particular farm.

- Surface-irrigation cutoff recommendations remain unsupported.
- Local measurements, crop/soil applicability, and independent specialist review are
  required before relying on field recommendations.
- French and Traditional Chinese field guidance still needs independent language and
  grower usability review.
- Nutrient accounting is not an automatic fertilizer or pesticide prescription.
- Additional agricultural enterprises and broader whole-farm optimization remain future
  work.
